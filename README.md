## 🚀 Áreas de Dominio Técnico

<details>
<summary><b>💻 Desarrollo de Software y Arquitectura de Sistemas</b></summary>

<br>

- **Sistemas POS e Inventarios:** Diseño y arquitectura conceptual e implementación de sistemas digitales de gestión comercial y puntos de venta (POS) orientados a Pequeñas y Medianas Empresas (PyMEs), abarcando desde la base de datos hasta la interfaz final (proyecto **STAK**).
- **Diseño de APIs REST:** Arquitectura e integración de servicios RESTful para conectar interfaces web con bases de datos relacionales de forma eficiente.

</details>

<details>
<summary><b>📈 Business Intelligence (BI) y Data Analytics</b></summary>

<br>

- **ETL (Extract, Transform, Load):** Extracción, limpieza, validación y preparación de conjuntos de datos heterogéneos para análisis de rendimiento comercial y marketing.
- **Visualización de Datos & BI:** Manejo y comprensión de herramientas como Power BI y tableros de control para la toma de decisiones estratégicas basadas en métricas clave.
- **Decision Intelligence:** Aplicación de modelos cuantitativos y cualitativos para soportar el proceso de toma de decisiones dentro de modelos de negocio digitales.

</details>

<details>
<summary><b>🌐 Redes y Telecomunicaciones</b></summary>

<br>

- **Configuración de Redes (Cisco Packet Tracer):** Diseño y simulación de topologías de red, direccionamiento IP (IPv4), configuración de routers/switches y despliegue de telefonía sobre IP (IP Telephony / VoIP) incluyendo la asignación y gestión de extensiones `ephone`.

</details>

<details>
<summary><b>🎮 Diseño Interactivo y Entornos 3D</b></summary>

<br>

- **Desarrollo Interactivo:** Modelado conceptual y pruebas en motor de videojuegos (**Godot 4** y **Unity**) para la simulación de entornos interactivos (layouts de mapas, mecánicas de interacción y cámaras).
- **Modelado 3D:** Creación y optimización básica de objetos y entornos dentro de **Blender** para su exportación e integración en motores de renderizado.

</details>

## 🏆 Proyecto Destacado: STAK

<div align="center">

### 🛒 Sistema POS e Inventarios para PyMEs

**STAK** es un sistema de punto de venta y gestión de inventarios diseñado
para digitalizar y optimizar las operaciones comerciales de pequeñas y
medianas empresas.

| Característica | Descripción |
|:---|:---|
| 🎯 **Objetivo** | Digitalizar la gestión comercial y de inventarios de PyMEs |
| 🧩 **Alcance** | Desde la base de datos hasta la interfaz final |
| 🛠️ **Stack** | Python · FastAPI · PostgreSQL · Vue.js |
| 📦 **Módulos** | Punto de venta, inventarios, reportes, usuarios |

</div>
